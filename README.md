# 海带索引图 FILM

一个纯前端胶片索引图（contact sheet）生成器。把扫描后的单张底片图片整理为 135、半格、120 中画幅的索引图。图片只在浏览器本地处理，不上传服务器。

> 本项目基于 [Judian99/film-index-generator](https://github.com/Judian99/film-index-generator) 二次开发，v1.2.0 新增「A4 竖向（真实底片尺寸）」分页排版、合并/分页导出与 PDF 导出能力。

## 快速开始

### 1. 在线使用

访问：<https://ohsobrkn.github.io/film-index-generator/>

### 2. 下载 Release 压缩包

本项目是纯前端静态网页，无需安装依赖或运行构建命令。

1. 前往 [Releases 页面](https://github.com/ohsobrkn/film-index-generator/releases)，下载最新版本的 ZIP 压缩包。
2. 将压缩包完整解压到本地文件夹。
3. 进入解压后的目录，用浏览器打开 `index.html`。

### 3. 使用 Git Clone

如需获取最新源码或参与开发，可以克隆仓库：

```bash
git clone https://github.com/ohsobrkn/film-index-generator.git
cd film-index-generator
```

然后用浏览器打开 `index.html`。

### 使用方法

1. 点击“选择或拖入扫描件”，或直接把 JPG/PNG/WebP 文件拖入窗口。
2. 等待图片加载完成，自动生成索引图。
3. 使用侧栏调整排版、画幅和胶片外观；背景可选淡黄纸底、纯白或高斯模糊。「胶片外观」中可切换片头方向：默认片头在左；选择「片头在右」后片头图案镜像至首行右侧，照片序号自右向左排列，片尾移至末行左侧；末行照片不足整行时整体右对齐、自右边缘顶格排布。
4. 点击“观片台”或按 `F` 进入沉浸检片模式。移动鼠标在整张索引上使用观片器，滚轮无极调节倍率（1X–60X）；左键单击切换聚焦/非聚焦模式，按 `Esc` 退出。触控设备可点按切换聚焦。
5. 点击“导出索引图”下载 PNG 或 JPG。导出弹窗可保持当前比例，也可选择 A4 竖向（1:√2）、横向（√2:1）、「单张A4（自适应整页）」或「**A4 竖向（真实底片尺寸）**」；A4 模式会自动优化每行张数并居中扩展画布，不裁切照片。「单张A4」会连同顶部信息区块一起自适应：自动匹配页面方向与每行张数、按内容动态调整照片尺寸与行距，使全部内容完整排满单张 A4 页面、互不遮挡；新增「以 A4 横向输出」勾选项，未勾选时默认按 A4 竖向导出，勾选后才允许自适应为横向页面。「A4 竖向（真实底片尺寸）」按 300dpi（210mm = 2480px）锁定 A4 页面，将 135 标准帧以 **36 × 24 mm 原大**排印、打印即与真实底片 1:1 对应：帧宽/列数不受侧栏控制（侧栏「尺寸基准」「每行张数」自动锁定），列数由页面内容宽自动最大化（135 全画幅为每页 5 列）、行数按页高自动分页（行不跨页，首页扣除信息区块预留），信息区块与胶片照片按与「单张A4」一致的逻辑整页居中，主预览同步切换为逐页显示（几页 A4 就显示几页，与打印效果一致），导出弹窗实时显示「A4 × N 页 · 每页 X 列 · 单帧 36 × 24 mm · 导出方式」排版摘要。PNG/JPG 导出提供两种方式：**合并成一张**（全部页面纵向堆叠为一张无缝长图，页间不留缝隙）或**分页导出**（每页单独一个文件，文件名含 `page1of2` 等页码）；预览页会随所选方式同步更新（分页显示页间工作台缝隙，合并显示无缝长图）。另有「**导出 PDF**」按钮（位于确认导出左侧），可选 150 / 300 / 600 DPI 打印分辨率，逐页渲染为 JPEG 后封装为标准 PDF（页面固定 210 × 297 mm），直接送印即可。仅支持 135 家族画幅（全画幅 / 宽幅 / 半格），120 画幅选择该项时自动回退当前比例并提示。
6. 导出弹窗中可开启「顶部显示索引信息区块」：在索引图上方生成 FILM / DATE / CAMERA·LENS / REMARKS 手写字段行，默认**磨砂玻璃底**（把区块背后的画面放大、高斯模糊、降饱和后透出，叠暖白半透明层、1px 高光描边与细腻颗粒，模拟真实磨砂亚克力/摄影档案卡质感）；另有四种主题模板——经典胶片（墨框 + 红色点缀）、简洁框线（浅框 + 红色强调）、极简线条（竖线分隔 + 书写基线）、暗房夜色（深底亮字）；底色可自由选择（半透明跟随背景 / 不透明纸底 / 纯白 / 深色 / 内置**做旧牛皮纸**与**做旧羊皮纸**纹理 / 透明），纹理底同样支持不透明度与模糊调节；不透明度、模糊与框圆角三个滑块都带实时数值显示，**点按或拖动其中任一滑块**，导出弹窗的外壳（暗色遮罩与其余配置项）会渐隐消失、整个页面随之变清晰，这三个滑块则以一块毛玻璃卡片**原地悬浮在预览图之上**并保持悬浮：卡片上方会显示「当前正在调整的选项名 · 即时数值」，正在拖动的滑块同步高亮，预览实时呈现模糊 / 圆角 / 不透明度的变化；点弹窗空白处、按 `Esc` 或点卡片上的「完成」退出悬浮、弹窗渐显恢复；字段宽度占比可在弹窗中微调（localStorage 记忆）；可导入透明底暗盒 PNG 并放置在区块左侧或右侧，自动等比缩放、垂直居中，**单击预览画布中的暗盒会弹出与单击照片完全相同的操作菜单**，菜单内可**调整暗盒尺寸**（50%–300%，默认 100%，数值实时显示，滑块带磁吸：最靠近「与框线精确等宽」临界值的整数百分比会自动吸附为准确值并弹出「暗盒尺寸已与框线等宽，此时为百分之XX」提醒（XX 为精确等宽所需的准确百分比），仅在精确相等的那一档触发、无提前触发与区间误触发，超出信息栏的部分自动裁掉；若图片过扁导致等宽临界值超出 50%–300% 量程，拖到 300% 上限时会提示「即使放大到 300% 高度也无法与框线等宽（需约百分之XX）」，不再静默）、**更换暗盒图片**、一键恢复默认；新增**边缘羽化开关**（开启后信息栏四周由清晰硬边变为柔和渐隐，边缘渗入下方胶片的模糊色彩与光影，如半透明亚克力嵌入照片；关闭恢复清晰矩形边界）与**框圆角滑块**（0% 保持当前样式，上调时包住四个字段框的外框与四个字段框取**同一个圆角值**、内外一致同步变化，数值实时显示）。字体内置 FOT-MatissePro 六档字重可选、按需加载。信息栏以 **135 画幅的观感为基准**：切换到 6×6 / 6×9 / 6×4.5 等 120 画幅时，区块高度、间距与字号按画布宽度等比收敛，并按各字段框宽度二次收缩标签字号，保证文字永不溢出框线、相邻标签互不遮挡。

观片器会放大整张索引内容（图片、齿孔、边字、片基与空白）。图片区直接读取裁切、旋转后的最终原分辨率画面，而不是放大预览图。通过百度网盘导入的照片会在首次稳定检视当前帧时按需获取原图。

## 编辑单帧

在预览图的某一帧上右键，打开帧操作菜单。

<p align="center">      
  <img src="docs/images/03-frame-menu.png" alt="帧操作菜单" width="680">      
</p>

### 裁切

打开裁切弹窗，拖动四个角调整裁切区域，点击"应用裁切"确认。

<p align="center">      
  <img src="docs/images/04-crop-editor.png" alt="裁切编辑器" width="680">      
</p>

### 旋转

每点击一次将帧顺时针旋转 90°，支持多次旋转。

### 插入

在当前位置前插入一张空白帧，用于占位或标记。

### 导出单帧

在帧操作菜单中选择“导出单帧”，可将当前画面导出为独立的片基单帧图片。输出会沿用当前图片的裁切、旋转和方向处理，并使用当前索引的画幅、胶卷型号、边字、齿孔、宽幅成像覆盖设置以及排序后的帧号。

正式版仅提供片基单帧效果，不包含拍立得或幻灯片片夹样式。弹窗支持 PNG、JPG，以及 1x、2x、3x 和原图级输出；原图级仅支持 PNG。若原图级单帧超过浏览器画布上限，页面会提示改用 3x。

### 删除

从索引图中移除该帧。

## 胶卷型号

### 内置型号(缓慢更新)

提供常见胶卷型号下拉选择，每种型号包含名称、边字字样、冲洗工艺等预设信息。

### 自定义型号

在"自定义型号"面板中可新增、编辑、删除胶卷型号：

- **名称**：显示名称
- **边字字样**：出现在索引图边字区域，留空表示底片无边字
- **冲洗工艺**：C-41 彩色负片、黑白负片、E-6 反转片、ECN-2 电影卷
- **高级外观**：可自定义边字颜色、交替字样、帧号格式

自定义型号保存在浏览器 localStorage 中，支持 JSON 导入导出。

## 隐私说明

- 图片只在浏览器本地读取和绘制，不上传服务器
- 不写入额外元数据
- 自定义型号数据保存在浏览器 localStorage 中，清除浏览器数据会丢失
